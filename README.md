# 雙軌並行 · 多部共治 · 邁向百年
## 一所 15 年一貫中英文雙部學校協同治理與團隊建設的行動研究

> **教育部「新時代中小學名師名校長培養計劃」北京大學培養基地**  
> **2026年10月29日 博士開題答辯專用匯報簡報引擎**

---

## 🌟 簡報特點與核心功能

本專案將《10-29_開題匯報PPT架構與40分鐘校長講稿_正式版.docx》完整轉化為全功能互動式網頁簡報引擎（Web Slide Deck），兼備高規格學術視覺美感與演練提詞實戰功能：

* **26 頁主簡報**：嚴格按照 40 分鐘開題匯報進程規劃（建議主講 34–35 分鐘，留 5–6 分鐘現場互動與切換），涵蓋七大核心板塊：
  1. 一、 開場與選題論證（Slide 1–4）
  2. 二、 學校現況與管治基線（Slide 5–8）
  3. 三、 研究問題與目標體系（Slide 9–11）
  4. 四、 理論支撐與概念框架（Slide 12–14）
  5. 五、 行動研究設計與方法論防禦（Slide 15–19）
  6. 六、 進度、成果與保障機制（Slide 20–24）
  7. 七、 結語與請益致謝（Slide 25–26）
* **10 頁應答備用頁（Backup Slides Arsenal）**：
  專為 Q&A 專家質詢環節打造，直擊痛點。包含倫理深防、71位幹部編制表、901節私框法條、雙部聯席SOP、量表信度檢驗、少子化深描案例、常態行政vs行動研究等武器，一鍵精準調用。
* **校長 40 分鐘現場匯報逐字講稿（Speaker Notes Drawer）**：
  按鍵 `S` 或點擊按鈕隨時呼出。精確標註時間進度（如 `[07:30 - 09:00]`）、眼神轉向（`【眼神轉向教青局領導】`）、重音強調與切換指引。
* **演講工具箱**：
  - ⏱️ 40 分鐘演講倒計時（30分鐘黃色預警、35分鐘紅色警告，按 `T` 暫停/繼續）。
  - 🖊️ 雷射筆演練模式（按 `P` 開關，紅光光暈跟隨鼠標）。
  - 🗂️ 36 頁全覽目錄縮圖導航（按 `O` 或 `Esc` 呼出）。
  - ⛶ 全螢幕沉浸投影模式（按 `F` 鍵）。
  - 📥 內建完整 PPTX 簡報與備註下載連結（包含同名文件與 `cdsj5_defense_deck_formal.pptx`）。
  - 🖨️ 列印與 PDF 輸出優化（`Ctrl+P` 可直接將 36 頁列印為高品質 16:9 PDF 文件）。

## ⌨️ 快捷鍵指南

| 快捷鍵 | 功能說明 |
|---|---|
| `→` / `↓` / `Space` / `PageDown` | 切換至下一頁投影片 |
| `←` / `↑` / `PageUp` / `Backspace` | 切換至上一頁投影片 |
| `Home` / `End` | 跳轉至第一頁 / 最後一頁 |
| `S` | 開啟 / 關閉校長現場逐字講稿抽屜 |
| `B` | 打開 10 頁答辯應答備用庫（Backup Arsenal） |
| `O` 或 `Esc` | 打開 / 關閉投影片全覽目錄網格 |
| `F` | 進入 / 退出全螢幕投影模式 |
| `P` | 開啟 / 關閉演講雷射筆指針 |
| `T` | 暫停 / 恢復 40 分鐘計時器 |
